# 3.4 vector的实现
本节写vector的实现。这个vector将是第一类类型（first-class type）：该vector的对象可以被复制，并且其所在内存可通过其析构函数自动释放。  

避免混淆，命名为Vector。  
该类主要细节如下：  
- Vector保留原始的数组，数组容量，数组当时存储在Vector中的项数。  
- 实现五大函数来提供深拷贝功能，提供析构函数回收原始数组，实现C++11的移动功能。  
- 提供改变Vector大小的resize方法，改变Vector容量的reserve方法。该容量通过为原始数组获取新的内存块、把旧内存块复制到新内存块并回收旧内存块来更新。  
- 提供operator[] 的实现。  
- 提供size、empty、clear、back、pop_back、push_back等基本方法。  
- 支持内嵌类型iterator和const_iterator，提供相关联的begin和end方法。
